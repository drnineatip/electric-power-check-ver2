คู่มือการใช้งานระบบ

ข้อแนะนำและวิธีการใช้งานระบบตรวจสอบสถานะไฟฟ้าส่องสว่าง

1. ภาพรวมระบบ

ระบบตรวจสอบสถานะไฟฟ้าส่องสว่างถูกออกแบบมาเพื่อรองรับการเฝ้าระวัง ตรวจสอบ และบริหารจัดการระบบโคมไฟฟ้าสาธารณะบนท้องถนนแบบ Real-time โดยรองรับการเข้าใช้งานหลายระดับสิทธิ์ ได้แก่ ผู้ใช้งานทั่วไป ผู้ตรวจสอบ และผู้ดูแลระบบ (Admin)

2. สัญลักษณ์สีสถานะโคมไฟ

  • สีเขียว (สว่างปกติ): โคมไฟทำงานสมบูรณ์ Brightness 100%
  • สีเหลือง (ไฟกระพริบ): แรงดันไฟฟ้าหรือระบบจ่ายไฟมีความผันผวน
  • สีส้ม (สว่างปานกลาง/แสงน้อย): ระดับความสว่าง 10%-50%
  • สีแดง (ไฟดับ): โคมไฟชำรุด หรือไม่มีกระแสไฟฟ้าจ่ายเข้าโคมไฟ (0%)

3. ขั้นตอนการแจ้งปัญหาและส่งงานซ่อม

  1. ไปที่เมนู 3 "ข้อมูลโคมไฟฟ้า" แล้วคลิกปุ่ม "แจ้งปัญหา"
  2. ในหน้าแจ้งปัญหา ให้เลือกโคมไฟที่สว่างน้อยกว่า 100% แล้วกด "แจ้งซ่อม"
  3. เลือกบริษัทผู้ให้บริการ (Outsource) ที่รับผิดชอบพื้นที่ กด "ยืนยันการเลือก" แล้วระบุ Email เพื่อส่งงาน
  4. ติดตามสถานะในเมนู 2 "ตรวจสอบสถานะการดำเนินการ" และปิดงานพร้อมประเมิน KPI ในเมนู 3 "ปิดงาน"

4. การจัดการระบบสำหรับ Administrator

สิทธิ์ Admin สามารถเพิ่ม/ลบผู้ใช้งาน, จัดการเพิ่ม/ลบโคมไฟฟ้า, ตั้งค่า Log Server และบริหารจัดการบริษัทผู้ให้บริการภายนอก (Outsource Management) ได้ในเมนู Administrator

ผู้ดูแลระบบ

1. จัดการผู้ใช้งานระบบ

ตรวจสอบ แก้ไข และเพิ่มผู้ใช้งานใหม่

เลขที่ผู้ใช้งาน ชื่อ นามสกุล แผนก Username สิทธิการใช้งาน สถานะ จัดการผู้ใช้

2. จัดการอุปกรณ์โคมไฟฟ้า

แสดงและจัดการอุปกรณ์โคมไฟฟ้าทั้งหมด 180 ดวง

ลำดับ / ชื่อโคมไฟฟ้า สถานที่ติดตั้ง สถานะการทำงาน จัดการ (ลบ)

3. ตั้งค่าสถานะการแจ้งเตือน

ตั้งค่าพารามิเตอร์เกณฑ์การแจ้งเตือนความผิดปกติของกำลังไฟฟ้า

4. Log Server Config

เชื่อมต่อระบบจัดเก็บ Log การทำงานทางไฟฟ้า

5. จัดการผู้ให้บริการภายนอก (Outsource Management)

รายการบริษัทผู้รับจ้างดูแลซ่อมบำรุงไฟฟ้าส่องสว่าง

ลำดับ บริษัท ที่ตั้ง งานที่รับผิดชอบ พื้นที่รับผิดชอบ 1 พื้นที่รับผิดชอบ 2 KPI คะแนน จัดการผู้รับจ้าง
